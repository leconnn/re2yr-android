# re2yr-android

**Command & Conquer: Red Alert 2** and **Yuri's Revenge**, rebuilt to run natively on Android.

You need your own copy of the original games. This app contains no EA game files: it plays using the files from the copy you own.

## Status
**In development. There is no playable build yet.**

## What you'll need to play
- An Android phone or tablet with a 64-bit (arm64) processor. Mid-range or better is recommended (Adreno 6xx or Mali-G7x class graphics).
- About 2.5 GB of free storage: 1.3 GB for the game files, plus room while they are copied.
- A legally owned copy of **Red Alert 2** and **Yuri's Revenge**, for example *The Ultimate Collection* from EA.

## How to install (once released)
1. Copy the game folder from your PC install to your phone, as a folder or a ZIP, by USB or cloud storage.
2. Install the APK. Allow installing apps from unknown sources if Android asks.
3. Open the app and pick the game folder or ZIP. The app checks the files and copies what it needs.
4. Choose **Red Alert 2** or **Yuri's Revenge** and play.

After the first import, the copied folder can be deleted and the app works offline.

## Planned features
- Both games, with the full Allied, Soviet and Yuri's Revenge campaigns.
- Skirmish against the computer.
- Multiplayer over LAN and the Internet.
- Touch controls designed for phones and tablets: tap to select and command, drag to box-select, pinch to zoom, and a touch-friendly build sidebar.
- Mouse, keyboard and controller support.
- Save and load, with auto-save when you leave the app.
